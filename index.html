maimai でらっくす レーティングチェッカー

ベスト枠(旧曲35)・新曲枠(15)・候補枠の対象曲を並べて、次の判定ランクまでの達成率と、そこに乗ったときのレート値の上昇量を出します。近い曲ほど上のグループに出るので、今日の1曲を選ぶ目安にどうぞ。譜面定数は otoge-db 由来の定数表を自動で読み込んで結合します。「でらっくすスコア枠」タブでは、達成率では見えない精度（でらっくすスコア）の伸びしろも確認できます。

目標を追加

条件に合う曲をまとめて目標にできます。達成した曲は自動でリストから消え、達成率が上がります。先に「レーティングチェッカー」でスコアデータを読み込んでおいてください。

定数の上限・下限は空欄でもOK（その場合は定数で絞りません）。定数が未確定の曲は、定数範囲を指定するとその条件では対象外になります。

スコアの取得には、音ゲーツール置き場（reiwa.f5.si）が公開しているデータ取得ブックマークレットを利用します。maimaiでらっくすNETにログインした状態で実行すると、このツールに読み込める maimai-player-data_*.json がダウンロードされます。CHUNITHM版と違い、APIトークンの発行や入力は不要です。

① データ取得ブックマークレット

下のリンクをブックマークバーに登録し、maimaiでらっくすNET（maimaidx.jp）にログイン・Aimeカードを選択した状態で実行してください。全難易度のスコアとRATING対象曲・候補曲を取得し、JSONファイルとして自動ダウンロードします（取得には数十秒かかります）。

🔖 maimaiスコア取得（ドラッグしてブックマーク登録）

登録方法①(ドラッグでそのまま登録): ブックマークバーを表示した状態で、上のリンクをブックマークバーへ直接ドラッグ&ドロップしてください。
登録方法②(クリックしてコピーし、手動で登録): 上のリンクをクリックすると、ブックマークレットのコードがクリップボードにコピーされます（クリックしてもページ内では何も実行されません）。ブラウザで新しいブックマークを作成し、URL欄にコピーしたコードを貼り付けて保存してください。
コピーがうまくいかない場合は bookmarklet.txt の中身を直接コピーしてもOKです。

使い方: maimaiでらっくすNETにログインし、Aimeカードを選択した状態で、登録したブックマークをクリックしてください。進捗ダイアログが表示され、完了すると maimai-player-data_*.json がダウンロードされます。それを「レーティングチェッカー」タブの「スコアデータを読込」またはドラッグ&ドロップで読み込んでください。
（RATING対象曲・候補曲の取得には有料プランの「maimai DX ネット」への加入が必要です。未加入の場合は候補枠が空になり、ベスト枠・新曲枠は全スコアから当ツールが推定して振り分けます。「でらっくすスコア枠」タブは全難易度のスコア一覧から作るため、有料プラン未加入でも利用できます。）

⚠️ ブックマークレットは maimaidx.jp（またはmaimaidx-eng.com）のページを開いた状態で実行してください。新しいタブページや設定画面など chrome:// から始まるブラウザ内部ページでは、外部通信が制限されて失敗します。

② 譜面定数データについて

maimaiのスコアJSONには譜面定数が含まれないため、レート値の算出には 音ゲーツール置き場 が公開している定数表(maimai_record.json / otoge-db 由来)をこのツールが自動で取得して結合します。取得した定数表はこのブラウザに一時キャッシュ(localStorage・約1.6MB)され、次回以降の読み込みを高速化します。
末尾に「?」が付く定数は、コミュニティ側で未確定・推定値であることを表します。

レート計算について

1曲のレート値 = floor(譜面定数 × min(達成率, 100.5) × 係数 ÷ 100) で算出しています（達成率は100.5%で頭打ち）。係数は判定ランクごとに SSS+:22.4 / SSS:21.6 / SS+:21.1 / SS:20.8 / S+:20.3 / S:20.0 / AAA:16.8 / AA:15.2 / A:13.6 / BBB:12.0 / BB:8.0 / B:4.0 / C:1.6。総合RATING = ベスト枠(旧曲)35曲 + 新曲枠15曲 の各レート値の合計です。maimaiでらっくすNET上の公式表示レーティングも参考として併記します。

利用にあたっての注意

スコアの取得・譜面定数表の利用は 音ゲーツール置き場 の各リソースに依存しています。取得したデータはご自身のプレイ記録の範囲でご利用ください。当ツールは非公式のファンツールであり、株式会社セガをはじめとする関係者・関係会社とは一切関係ありません。

※ 判定ランク境界値(達成率): D:0% / C:50% / B:60% / BB:70% / BBB:75% / A:80% / AA:90% / AAA:94% / S:97% / S+:98% / SS:99% / SS+:99.5% / SSS:100% / SSS+:100.5% / 理論値:101%
※ RATING = ベスト枠(旧曲)35曲のレート値合計 + 新曲枠15曲のレート値合計。maimaiでらっくすNET上のRATING対象曲(ベスト/新曲)をそのまま採用しています。候補枠はレートには直接算入されず、次にベスト/新曲枠へ入り得る曲の一覧です。
※ 「レート値」は譜面定数と達成率から当ツールが算出した値です。「加点」は次の判定ランクに到達したときのレート値の上昇量です。達成率100.5%を超える分はレートに加算されません。
※ 定数が赤字（末尾に「?」）はコミュニティ側で未確定・推定の値です。
※ 列見出しをクリックすると並び替えられます（評価グループの区切りは維持されます）。各行の「削除」でその曲を今の枠から外せます。データは消えないので「初期状態にリセット」で戻せます。
※ 画像として保存する際は、主要列（#・曲名・定数・達成率・判定ランク・次の達成率・次の判定ランク・差分）に絞って出力します。
※ 「でらっくすスコア枠」タブは、達成率では見えない精度（でらっくすスコア = CRITICAL PERFECT×3 + PERFECT×2 + GREAT、理論値 = 総ノーツ数×3）の指標です。✦（星）の基準は公式準拠で、達成率 85%〜✦1／90%〜✦2／93%〜✦3／95%〜✦4／97%〜✦5。RATINGには算入されません。
※ 「次のでらスコア」は次の✦ボーダーに到達するのに必要な、でらっくすスコアの絶対値です。でらっくすスコアの記録が無い譜面（未プレイ・データ未取得）はこのタブの対象外です。

当サイトは非公式のファンツールであり、株式会社セガをはじめとする関係者・関係会社とは一切関係ありません。
スコアデータの取得ブックマークレットおよび譜面定数表は 音ゲーツール置き場（reiwa.f5.si） のリソースを利用しています。譜面定数は otoge-db 由来です。ご利用の際は各配布元の方針に従ってください。
