# maimai でらっくす レーティングチェッカー

`maimai-rate-table.html` のピンク基調デザインを採用しています。

単一の `index.html` で動作します。ブラウザで開くだけで使えます（サーバー不要）。

## 何ができるか

- maimaiでらっくすNETから取得したスコアJSONを読み込み、**ベスト枠(旧曲35)・新曲枠(15)・候補枠**に振り分けて表示
- 各曲について **譜面定数・達成率・判定ランク・次のランクまでの達成率・そのときのレート上昇量（加点）** を計算
- 総合RATING（ベスト35 + 新曲15 のレート値合計）を算出し、公式表示レーティングと併記
- 判定ランクの範囲フィルタ、列ソート、曲の一時削除、画像保存
- 「目標」タブ: 条件（枠・定数範囲・難易度・目標ランク/達成率）で曲をまとめて目標化し、達成率を追跡
- 「設定・データ取得」タブ: スコア取得ブックマークレットの登録手順、譜面定数表の再取得

## 使い方

1. `index.html` をブラウザで開く。
2. 「設定・データ取得」タブのブックマークレットを登録し、maimaiでらっくすNETで実行して
   `maimai-player-data_*.json` をダウンロードする（詳細は [bookmarklet/README.md](bookmarklet/README.md)）。
3. 「レーティングチェッカー」タブで、そのJSONを読み込む（ファイル選択 / ドラッグ&ドロップ / 貼り付け）。

## レート計算

1曲のレート値:

```
floor(譜面定数 × min(達成率, 100.5) × 係数 ÷ 100)
```

係数（判定ランク別）: SSS+ 22.4 / SSS 21.6 / SS+ 21.1 / SS 20.8 / S+ 20.3 / S 20.0 /
AAA 16.8 / AA 15.2 / A 13.6 / BBB 12.0 / BB 8.0 / B 4.0 / C 1.6。

総合RATING = ベスト枠(旧曲)35曲 + 新曲枠15曲 の各レート値の合計。

## 譜面定数について

maimaiのスコアJSONには譜面定数が含まれないため、本ツールは
[音ゲーツール置き場（reiwa.f5.si）](https://reiwa.f5.si/) が公開している定数表
`maimai_record.json`（[otoge-db](https://github.com/zvuc/otoge-db) 由来）を実行時に取得し、
`title + 難易度 + DX/STD` をキーにスコアと結合します。取得した定数表はブラウザに一時キャッシュ
（localStorage・約1.6MB・7日間）されます。

## データの扱い

- 読み込んだスコアはブラウザのセッション内（sessionStorage）にのみ保持され、タブを閉じると消えます。
- 目標・定数キャッシュは localStorage に保存されますが、外部やサーバーには送信されません。
