# maimai でらっくす レーティングチェッカー

maimai のベスト枠・新曲枠・候補枠のスコアを読み込んで、次の判定ランクまでの必要スコアとレート上昇量を一覧表示するWebツールです。

- 🔗 **ツールを開く(GitHub Pages)**: https://odin3556.github.io/maimai-score-tool/
- 📄 **ソースコード**: このリポジトリ自体です([index.html](index.html)が本体)

## 何ができるか

- maimaiでらっくすNETから取得したスコアJSONを読み込み、**ベスト枠(旧曲35)・新曲枠(15)・候補枠**に振り分けて表示
- 各曲について **譜面定数・達成率・判定ランク・次のランクまでの達成率・そのときのレート上昇量（加点）** を計算
- 総合RATING（ベスト35 + 新曲15 のレート値合計）を算出し、公式表示レーティングと併記
- 判定ランクの範囲フィルタ、列ソート、曲の一時削除、画像保存
- 「でらっくすスコア枠」タブ: 全プレイ済み譜面のでらっくすスコア（精度）から ✦（星1〜5）と、次の✦までに必要な点数を表示。定数の範囲で絞り込み可（RATINGには算入しません）
- 「目標」タブ: 条件で曲をまとめて目標化し、レーティングチェッカーと同じ形の表で進み具合を追跡（詳しくは下記）
- 「設定・データ取得」タブ: スコア取得ブックマークレットの登録手順、譜面定数表の再取得

## 目標タブ

- **作り方**: 枠・定数範囲・難易度と、達成基準（判定ランク以上 / 達成率以上）を選んで作成。
  枠に「でらっくすスコア枠」を選ぶと達成基準は「✦以上」になり、さらに **「差分 N点未満」**（10 / 20 / 30 / 50 / 100 のボタンか手入力）で、
  選んだ✦まであとN点未満のまだ届いていない譜面だけに絞れます。
- **表示**: 目標ごとのタブと、「のこり / 全体・達成%・進捗バー」の要約、🔥〜🏆の評価グループ付きの表。
  列見出しをクリックで並び替え（定数順・目標までの残りの近い順など）。「練習」列の「動画」でYouTubeを検索。
- **チェック**: 各行の先頭のチェック欄をタップすると、スコアを読み込み直さなくても「🏆 到達済み」に移せます
  （緑＝手動チェック・もう一度タップで外す、ピンク＝スコアで達成済み）。「手動チェックN曲を戻す」でまとめて外せます。
- **画像保存**: 1目標ずつ、または全目標を1枚に。表の上に進捗の数値とバーを出し、チェック済みの曲は除いて未達成の曲だけを出力します。

## 使い方

1. `index.html` をブラウザで開く。
2. 「設定・データ取得」タブのブックマークレットを登録し、maimaiでらっくすNETで実行して
   `maimai-player-data_*.json` をダウンロードする（詳細は [bookmarklet/README.md](bookmarklet/README.md)）。
3. 「レーティングチェッカー」タブで、そのJSONを読み込む（ファイル選択 / ドラッグ&ドロップ）。

## レート計算

1曲のレート値:

```
floor(譜面定数 × min(達成率, 100.5) × 係数 ÷ 100)
```

係数（判定ランク別）: SSS+ 22.4 / SSS 21.6 / SS+ 21.1 / SS 20.8 / S+ 20.3 / S 20.0 /
AAA 16.8 / AA 15.2 / A 13.6 / BBB 12.0 / BB 8.0 / B 4.0 / C 1.6。

総合RATING = ベスト枠(旧曲)35曲 + 新曲枠15曲 の各レート値の合計。

## でらっくすスコアの✦

でらっくすスコア = CRITICAL PERFECT×3 + PERFECT×2 + GREAT、理論値 = 総ノーツ数×3。
理論値に対して 85% で✦1 / 90% で✦2 / 93% で✦3 / 95% で✦4 / 97% で✦5（公式準拠）。
必要な点数は譜面ごとの理論値から `ceil(理論値 × ボーダー%)` で計算します。

## 譜面定数について

maimaiのスコアJSONには譜面定数が含まれないため、本ツールは
[音ゲーツール置き場（reiwa.f5.si）](https://reiwa.f5.si/) が公開している定数表
`maimai_record.json`（[otoge-db](https://github.com/zvuc/otoge-db) 由来）を実行時に取得し、
`title + 難易度 + DX/STD` をキーにスコアと結合します。取得した定数表はブラウザに一時キャッシュ
（localStorage・約1.6MB・7日間）されます。

## データの扱い

- 読み込んだスコアはブラウザのセッション内（sessionStorage）にのみ保持され、タブを閉じると消えます。
- 目標・定数キャッシュは localStorage に保存されますが、外部やサーバーには送信されません。
